# 踩过的坑

> 都是做这个工具时真实撞上的。人和机都值得读一遍，尤其是要改样式、换卡面的时候。

## iPhone / Safari

**1. 卡角发黑或发白**
卡面图本身四角留了白边或黑底，配上 3D 翻面以后，Safari 会把圆角外面那一圈画出来。
→ 卡面图要裁掉外圈、四个角抠成透明圆角（自带那套已经处理过）；CSS 里不要在做 3D 翻面的那一层上用 `overflow:hidden` + 圆角，圆角给图片自己（`card-view` / `cards.css` 已经这么做了）。换卡面时尤其注意这条。

**2. 字体看起来没变**
iOS 上 PWA 和 Safari 会死死缓存 CSS / JS。改了样式没效果，先怀疑缓存：给文件加 `?v=版本号`，每次改动都换。

**3. 震动**
翻面时调了 `navigator.vibrate`，iPhone 不支持，什么都不会发生，这是正常的，不是坏了。

## 排版

**4. 外框的内边距会吃掉一行的宽度**
很多站点全局写了 `* { box-sizing: border-box }`。卡片一排排开时，如果容器有左右内边距，内容区就比你算的窄，一行本来放得下三张，结果挤成两张、甚至三行。
→ 改扇子 / 卡片排布时，在带 border-box 的真实页面里测，不要只在空白测试页里测。

**5. 同样优先级的 CSS，后写的赢**
`.dc-draw-hand .dc-draw-cards` 和 `.dc-draw-hand-5 .dc-draw-cards` 优先级一样，写在后面的那条会覆盖前面的。想按张数单独调，就写在通用规则后面。

**6. 一手卡在聊天里悬在中间**
扇子的外框太宽，扇子在框里居中，看起来就不跟气泡对齐。外框要收紧到刚好包住整把牌（`cards.css` 里按张数给了宽度），再靠父元素的 `align-items` 贴到左边或右边。

## 导入

**7. 全角括号**
手机输入法打出来的方括号常常是全角的「［真心话］」或「【真心话】」。导入规则半角、全角、【】都认；手动加卡时，标签框空着而题目开头带括号的，也会自动拆成标签。

**8. 权重和正文里的 x**
权重写在一行最后：`麻辣烫 ×3`，前面**必须**有一个空格，否则 `Max` 结尾的 x 会被当成权重符号。× 也可以写 x、X、*。

**9. AI 整理题库时多出来的东西**
让 AI 照模板整理时，它常常会加 Markdown 代码块（```）或者在权重前面漏空格。导入前一定先看预览，有问题的行会标出来。模板最上面有一段话可以直接复制给 AI，减少这种情况。

## 抽卡流程

**10. 点「抽」没反应**
记抽卡偏好时如果只发改动的那一项（比如只改了张数），服务器回来的偏好里没有卡池，前端就以为没选卡池，静默不抽。`draw-panel.js` 现在每次都把当前卡池一起带上，并且所有不能抽的情况都会给出提示——你们改这块时别把这两点改丢了。

**11. 抽完别直接发**
早期版本抽完立刻作为一条消息发出去，YOU 就没法配文字、表情包、语音了，也没法重抽。现在抽完先挂在输入框上；「重抽」「放回」会调 `/cards/draws/:id/void` 把卡退回这一轮，发出去以后服务器拒绝退回。
