// ================================================================
// 给你抽一张 · 卡池导入模板 v3
// ================================================================
// 这份文件可以原样导入：所有以 // 开头的行都是说明，导入时自动跳过，不用删。
// 系统按固定规则一行一行识别，不经过任何模型。
//
// 想让 AI 帮你整理？把这整份文件和你的原始内容一起发给它，说：
// 「请严格按这份模板的规则，把我给的内容整理成 卡池格式，
//   只输出整理好的结果，不要解释，不要加 Markdown 代码块。」
//
// ----------------------------------------------------------------
// 一、卡池头（每个卡池开头写几行，以井号 # 开头）
// ----------------------------------------------------------------
//   # 卡池：名字      ← 必填。一行一个卡池名。遇到下一行「# 卡池：」就开始新卡池
//   # 说明：一句话    ← 可选
//   # 放回：否        ← 可选，只能写「是」或「否」，不写默认「否」
//                       否 = 抽过的这一轮不再出现，全部抽完自动洗牌（真心话、单词卡）
//                       是 = 每次都从全部卡里抽，可能重复抽到（今天吃什么、去哪玩）
//
//   格式细节：
//   · 井号 # 后面有一个空格
//   · 冒号用中文全角「：」或英文半角「:」都可以
//   · 冒号后面有没有空格都可以
//
// ----------------------------------------------------------------
// 二、卡（一行 = 一张卡）
// ----------------------------------------------------------------
//   完整写法：  [标签] 正面文字 || 反面文字 ×权重
//   最简写法：  正面文字
//
//   [标签]      可选。方括号包住，放在行首。一张卡只放一个标签。
//               例：[真心话] [大冒险] [早饭] [粉面] [周末去哪]
//               抽卡时可以按标签筛选。
//   正面文字    必填。抽到时先看到的内容。
//   || 反面     可选。两个竖线隔开，后面是翻过来才看到的内容（答案、释义、提示）。
//   ×权重       可选。写在一行最后。×3 = 被抽中的机会是普通卡的 3 倍。
//               × 可以写成 x 或 X 或 *，后面是 1 到 99 的整数。不写就是 ×1。
//
//   格式细节：
//   · [标签] 和正面文字之间：一个空格（不写空格也认）
//   · || 两边：各一个空格（不写空格也认）
//   · ×权重 前面：一个空格（必须有，防止把正文里的 x 误认成权重）
//   · 一张卡必须写在同一行里，中间不能回车。
//     卡里想换行，就写 \n （反斜杠加小写 n），显示时会变成换行。
//   · 正文里不要出现 || ，它是专门用来分正反面的。
//
// ----------------------------------------------------------------
// 三、其他
// ----------------------------------------------------------------
//   · 空行会被忽略，可以随便空行分隔
//   · 以 // 开头的行是注释，会被忽略
//   · 一个文件里可以放很多个卡池
//   · 同一个卡池里重复的卡会被提示，可以选择跳过
//   · 文件存成 UTF-8 编码的 .txt
//
// ================================================================
// 下面是示例，导入时会真的建出这三个卡池。不需要的话整段删掉。
// ================================================================

# 卡池：真心话大冒险·第一批
# 说明：小红书上扒来的，国庆夜里玩
# 放回：否

[真心话] 你第一次心动是什么时候？
[真心话] 手机相册里最后一张照片是什么？
[大冒险] 用最肉麻的语气叫对方一声老公
[大冒险] 发一条语音：先唱一句歌，\n再说一句「我爱你」

# 卡池：今天吃什么
# 说明：选择困难就抽一张
# 放回：是

[粉面] 牛肉粉
[粉面] 清汤肉丝粉
[麻辣烫] 楼下那家围炉麻辣烫 ×3
[轻食] 鸡胸肉沙拉
[火锅] 牛油火锅 ×2

# 放回：否
